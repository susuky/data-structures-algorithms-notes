題目連結怎麼看：「對應原題」表示解題目標相同，例子與解說由本教材編寫；「改編題型」會列出介面或條件的調整；「相近題型／延伸練習」會說明差異，不能直接當成同一題；「自編題／自編範例」依教材列出的條件作答。題意、輸入輸出與例子都保留在教材內，只有開啟外部題目連結時需要網路。

Python 範例以 Python 3 撰寫。互動實驗刻意限制小輸入，方便逐步觀察；實驗的視覺化追蹤會儲存每一步，不能拿它的記憶體成本代替原演算法的空間複雜度。
