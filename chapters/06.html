06 · 在樹與圖裡找到正確的路

走訪的順序決定什麼時候能使用答案。DFS 沿路深入，BFS 按距離分層，拓樸排序則讓前置工作先完成。

節點代表什麼，邊允許什麼

樹用父子關係組織資料，圖用邊表示可以前往的狀態。開始走訪前，先把邊的方向、權重與重複路徑說清楚：無向邊需要兩邊都能走，有向邊只沿指定方向。

二元樹 Node 保存 value、left、right。一般圖可用鄰接串列 graph[u] 保存 u 的鄰居，儲存成本 O(V+E)。樹的子節點關係若確保無環且無共享，沿子節點即可；一般圖則透過 seen 避免重訪。

每一個狀態還應包含會影響未來選擇的資訊。座標、已用資源、轉乘次數，後面會逐步加入。

from __future__ import annotations
from collections import deque
from dataclasses import dataclass

@dataclass
class Node:
    value: int
    left: Node | None = None
    right: Node | None = None

看推理

只會看到從 A 可到達的節點。要找整張無向圖的連通分量，需要從每個尚未看過的節點再啟動走訪。

進入、經過、返回，在哪個時刻做事

深度優先搜尋（DFS）沿一條路走到底，再回到上一層。前序在進入節點時處理，得到根→左→右；中序在左子樹完成後處理，得到左→根→右；後序在兩邊完成後才處理。

求樹高需要子樹先回傳，所以使用後序：height(node)=1+max(height(left),height(right))。本章高度以邊數計，葉節點為 0、空樹為 −1。

顯式堆疊做前序時，先推右再推左，讓 LIFO 下一次先取左。遍歷時間 O(n)，額外堆疊空間看樹高 h，常用寫法為 O(h)，輸出另計；退化成長鏈時 h 可達 n。

def preorder(root: Node | None) -> list[int]:
    if root is None:
        return []
    result, stack = [], [root]
    while stack:
        node = stack.pop()
        result.append(node.value)
        # LIFO: push right first so left is visited first.
        if node.right is not None:
            stack.append(node.right)
        if node.left is not None:
            stack.append(node.left)
    return result

def inorder(root: Node | None) -> list[int]:
    result = []

    def visit(node: Node | None) -> None:
        if node is None:
            return
        visit(node.left)
        result.append(node.value)
        visit(node.right)

    visit(root)
    return result

def tree_height(root: Node | None) -> int:
    # Height is measured in edges: empty = -1, leaf = 0.
    if root is None:
        return -1
    return 1 + max(tree_height(root.left), tree_height(root.right))

把同一層一起取出

廣度優先搜尋（BFS）把根放進佇列，取出後把左右孩子接到尾端。當要分層輸出時，每輪先讀取當下的佇列長度，恰好處理這麼多個節點。

處理這一層的過程中，新孩子會陸續入列，但它們屬於下一層。固定本輪次數，就能把兩層分開。

空樹回傳 []。每個節點進出一次，時間 O(n)；佇列峰值取決於最大層寬 w，空間 O(w)，分層輸出另計 O(n)。

def level_order(root: Node | None) -> list[list[int]]:
    if root is None:
        return []
    result, queue = [], deque([root])
    while queue:
        level = []
        for _ in range(len(queue)):
            node = queue.popleft()
            level.append(node.value)
            if node.left is not None:
                queue.append(node.left)
            if node.right is not None:
                queue.append(node.right)
        result.append(level)
    return result

祖先留下的範圍，一路往下傳

二元搜尋樹（BST）左子樹的所有值都小於根，右子樹的所有值都大於根。查詢 target 時，比根小就往左、大就往右，每次排除另一整棵子樹。

把搜尋目標換掉，沿著大小關係走一次，再往下看如何驗證整棵樹的範圍。

驗證 BST 時，把允許範圍 (lower,upper) 隨路徑傳下去。若根為 12，右子樹中的每個節點都必須大於 12；右孩子 18 的左孩子若為 9，雖然 9<18，卻已違反祖先下界。

本章採嚴格 BST，重複鍵不通過。搜尋時間 O(h)，平衡樹 h=O(log n)，長鏈 h=O(n)。驗證會看每個節點，時間 O(n)。

def bst_search(root: Node | None, target: int) -> Node | None:
    while root is not None:
        if root.value == target:
            return root
        root = root.left if target < root.value else root.right
    return None

def is_valid_bst(root: Node | None) -> bool:
    # Strict BST: duplicate keys are not permitted.
    stack = [(root, None, None)]
    while stack:
        node, lower, upper = stack.pop()
        if node is None:
            continue
        if lower is not None and node.value <= lower:
            return False
        if upper is not None and node.value >= upper:
            return False
        stack.append((node.right, node.value, upper))
        stack.append((node.left, lower, node.value))
    return True

入堆疊前，就標記已發現

圖可能有環，也可能有多條路通往同一節點。把起點放進 seen；每次發現新鄰居時，先加入 seen 再推入堆疊，讓其他路徑知道它已排入工作清單。

這個時機能避免同一節點被重複推入。dfs_reachable 回傳從起點可到達的節點集合，不要求最短路徑。

鄰接串列中每個可達節點與其邊最多檢查常數次，時間 O(V+E)，seen 與堆疊空間 O(V)。遇到多個分量時，在外層從尚未 seen 的節點重新出發。

def dfs_reachable(graph: list[list[int]], start: int) -> set[int]:
    seen, stack = {start}, [start]
    while stack:
        node = stack.pop()
        for neighbor in graph[node]:
            if neighbor not in seen:
                seen.add(neighbor)  # Mark before pushing.
                stack.append(neighbor)
    return seen

A 的鄰居依序是 B、C，另有 C→B。為什麼要在入堆疊時標記 B？

看推理

處理 A 後，堆疊由底到頂是 [B,C]。LIFO 先取出 C，此時 B 還在等待；C 沿邊看到 B 時，seen 已經記有 B，因此略過。若延到彈出 B 才標記，這一步會再推入一份 B。

先找到的，為何就是最少邊數

所有邊走一次的成本相同時，BFS 先處理距離 0，再處理距離 1、2……。節點第一次從距離 d 的節點被發現，就取得距離 d+1；更短層的節點已經在它之前處理完。

無權圖最短距離

每一步維持的關係

首次入列就設距離；FIFO 讓距離按層增加。

O(V+E) 時間、O(V) 額外空間。

互動顯示距離、父節點與待處理佇列。改成不連通案例，無法抵達的節點保留 ∞。圖上第一次發現的邊形成一棵搜尋樹；parent 讓你從終點一路回到起點，再反轉成路徑。

shortest_path 回傳節點路徑，起終點相同時回傳 [start]，不可達回傳 None。時間 O(V+E)、額外空間 O(V)。權重只有 0、1 時，用 deque 實作 0–1 BFS；一般非負權重用 Dijkstra；含負權重時可依圖的條件選 Bellman–Ford 或 DAG 最短路徑。

def shortest_path(graph: list[list[int]], start: int,
                  target: int) -> list[int] | None:
    parent = {start: None}
    queue = deque([start])
    while queue:
        node = queue.popleft()
        if node == target:
            path = []
            while node is not None:
                path.append(node)
                node = parent[node]
            return path[::-1]
        for neighbor in graph[node]:
            if neighbor not in parent:
                parent[neighbor] = node
                queue.append(neighbor)
    return None

網格中的鄰居，現場產生

迷宮不需要先建立完整的邊清單。節點是 (row,col)，每次嘗試上下左右四個方向，再篩選邊界內、可走且尚未發現的位置。

grid_distance 從左上走到右下，0 是通道、1 是牆，距離計移動次數。只有一格且可走時回傳 0；空網格、起終點被擋或不可達回傳 −1。輸入每列長度應一致。

R×C 個格子各檢查四個鄰居，時間 O(RC)、額外空間 O(RC)。若加上一次穿牆機會，節點就擴充成 (row,col,used)，把是否已消耗資源加入 seen。

def grid_distance(grid: list[list[int]]) -> int:
    # 0 = open, 1 = wall. Return the number of moves, not cells.
    if not grid:
        return -1
    rows, cols = len(grid), len(grid[0])
    if any(len(row) != cols for row in grid):
        raise ValueError('grid must be rectangular')
    if cols == 0:
        return -1
    if grid[0][0] or grid[-1][-1]:
        return -1
    queue = deque([(0, 0, 0)])
    seen = {(0, 0)}
    while queue:
        row, col, distance = queue.popleft()
        if (row, col) == (rows - 1, cols - 1):
            return distance
        for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
            nr, nc = row + dr, col + dc
            if (0 <= nr < rows and 0 <= nc < cols
                    and grid[nr][nc] == 0 and (nr, nc) not in seen):
                seen.add((nr, nc))
                queue.append((nr, nc, distance + 1))
    return -1

前置工作都完成，才加入待辦

邊 u→v 表示 u 要先於 v 完成。入度（indegree）是尚未完成的前置數量。Kahn 拓樸排序先把入度 0 的節點放進佇列，每取出一項，就把它的後續節點入度減一。

某個後續節點降到 0，就表示它的所有前置都已處理，可以排入佇列。得到的順序讓每條邊的起點都排在終點前面。

若取出的節點少於 V，剩下的節點互相等待，圖中有有向環；函式回傳 None。空圖回傳 []，多個合法順序都可接受。時間 O(V+E)、額外空間 O(V)。

def topological_order(graph: list[list[int]]) -> list[int] | None:
    """邊 u → v 表示 u 必須先於 v；有環回傳 None，空圖回傳 []。"""
    indegree = [0] * len(graph)
    for neighbors in graph:
        for neighbor in neighbors:
            indegree[neighbor] += 1
    ready = deque(node for node, degree in enumerate(indegree) if degree == 0)
    order = []
    while ready:
        node = ready.popleft()
        order.append(node)
        for neighbor in graph[node]:
            indegree[neighbor] -= 1
            if indegree[neighbor] == 0:
                ready.append(neighbor)
    return order if len(order) == len(graph) else None

def leaf_sum(root: Node | None) -> int:
    if root is None:
        return 0
    total, stack = 0, [root]
    while stack:
        node = stack.pop()
        if node.left is None and node.right is None:
            total += node.value
        if node.right is not None:
            stack.append(node.right)
        if node.left is not None:
            stack.append(node.left)
    return total

def component_sizes(graph: list[list[int]]) -> list[int]:
    # graph must be undirected; every edge is represented both ways.
    seen, sizes = set(), []
    for start in range(len(graph)):
        if start in seen:
            continue
        seen.add(start)
        stack, size = [start], 0
        while stack:
            node = stack.pop()
            size += 1
            for neighbor in graph[node]:
                if neighbor not in seen:
                    seen.add(neighbor)
                    stack.append(neighbor)
        sizes.append(size)
    return sizes

def grid_one_break(grid: list[list[int]]) -> int:
    # At most one wall cell may be entered; start/end must be open.
    if not grid:
        return -1
    rows, cols = len(grid), len(grid[0])
    if any(len(row) != cols for row in grid):
        raise ValueError('grid must be rectangular')
    if cols == 0:
        return -1
    if grid[0][0] or grid[-1][-1]:
        return -1
    queue = deque([(0, 0, 0, 0)])  # row, col, used, moves
    seen = {(0, 0, 0)}
    while queue:
        row, col, used, moves = queue.popleft()
        if (row, col) == (rows - 1, cols - 1):
            return moves
        for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
            nr, nc = row + dr, col + dc
            if 0 <= nr < rows and 0 <= nc < cols:
                next_used = used + grid[nr][nc]
                state = (nr, nc, next_used)
                if next_used <= 1 and state not in seen:
                    seen.add(state)
                    queue.append((nr, nc, next_used, moves + 1))
    return -1

從答案需要的順序選走法

只問可達、連通分量或需要回傳子樹答案，用 DFS；所有移動等成本、要求最少步數，用 BFS；有前置依賴、要找可執行順序，用拓樸排序。

在寫 seen 前，把節點的含義講完整。若未來還受穿牆次數、轉乘上限或時間限制影響，那些維度就屬於狀態。

回傳規格也要具體：路徑包含哪些節點，距離計邊還是格子，無解用什麼值。從起點等於終點、孤立點、有環與不連通各走一次，能快速看出狀態是否合理。
