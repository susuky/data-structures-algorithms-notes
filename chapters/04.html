04 · 沿著 next 改變串列

鏈結串列的重點在連結。保住剩下資料的入口，就能在原節點上反轉、刪除、合併；這章把每一次改線拆開來看。

兩個相同數值，可以是不同節點

節點保存 value 與 next。兩個節點都寫著 2，仍可位於串列的不同位置；比較它們是否同一個節點，使用物件身分 is。下方 Node 把值的相等與節點身分分開。

串列從 head 沿 next 走到 None。已知某個節點與前驅時，插入或刪除可改少量連結；要找第 k 個節點，仍需沿路前進，花 O(k)。陣列的索引存取則可直接定位。

from_values 建立節點，to_values 沿無環串列收集值，方便觀察結果。解法若只用幾個指標重接原節點，額外空間為 O(1)；把整條串列轉成清單會另用 O(n) 空間。

from dataclasses import dataclass
from typing import Optional

@dataclass(eq=False)
class Node:
    value: int
    next: Optional["Node"] = None

def from_values(values):
    dummy = Node(0)
    tail = dummy
    for value in values:
        tail.next = Node(value)
        tail = tail.next
    return dummy.next

def to_values(head):
    """僅用於有限、無環串列；測試工具不算進解法的額外空間。"""
    result = []
    while head is not None:
        result.append(head.value)
        head = head.next
    return result

反轉鏈結串列

每一步維持的關係

prev 是已反轉部分的入口；cur 是待處理部分的入口。

O(n) 時間、O(1) 額外空間。

prev 是已反轉部分的入口，cur 是未處理部分的入口。保存 nxt 是兩部分之間的接續點；若先覆寫 cur.next，就會失去尚未走過的尾段。

cur 走到 None 時，prev 正好指向原本最後一個節點。每個節點改一次 next，時間 O(n)、額外空間 O(1)。空串列回傳 None，單節點回傳原節點。

def reverse(head):
    prev, cur = None, head
    while cur is not None:
        following = cur.next
        cur.next = prev
        prev, cur = cur, following
    return prev

一個走一步，一個走兩步

找中點時，slow 每輪走一格，fast 走兩格。fast 走到尾端，slow 就走了約一半。這裡的 middle_second 對偶數長度回傳第二個中點：四個節點回傳索引 2；空串列回傳 None。

有環時，fast 進環後每輪相對 slow 多走一格，兩者終會相遇。相遇後，把另一個指標放回 head，兩者都一次走一格，再次相遇的位置就是環入口。

設 head 到入口長度 μ，slow 從入口到首次相遇處走了 x，環長 λ。快慢距離差是 λ 的整數倍，得到 μ+x 為 λ 的整數倍；從相遇處再走 μ 步會回到入口。cycle_entry 以 is 比節點身分，時間 O(n)、空間 O(1)，無環回傳 None。

def middle_second(head):
    """偶數長度時回傳第二個中點；空串列回傳 None。"""
    slow = fast = head
    while fast is not None and fast.next is not None:
        slow = slow.next
        fast = fast.next.next
    return slow
Python · cycle_entry
def cycle_entry(head):
    slow = fast = head
    while fast is not None and fast.next is not None:
        slow = slow.next
        fast = fast.next.next
        if slow is fast:
            seeker = head
            while seeker is not slow:
                seeker = seeker.next
                slow = slow.next
            return seeker
    return None

用固定距離找到倒數位置

要刪倒數第 k 個節點，讓 fast 比 slow 超前 k 格，再一起往右走。當 fast 到最後一個節點，slow 就停在待刪節點的前一個位置。

在 head 前放一個 dummy，讓「刪第一個節點」也能使用 slow.next=slow.next.next。兩個指標都從 dummy 出發，fast 先走 k 格；走不滿代表 k 超過長度，程式在改線之前回報 ValueError。

k 必須為正，合法時回傳 dummy.next。整條串列最多走常數次，時間 O(n)、額外空間 O(1)。

def remove_from_end(head, k):
    """移除倒數第 k 個節點；k 無效時拋 ValueError 且不修改串列。"""
    if k <= 0:
        raise ValueError("k 必須為正整數")
    dummy = Node(0, head)
    slow = fast = dummy
    for _ in range(k):
        fast = fast.next
        if fast is None:
            raise ValueError("k 大於串列長度")
    while fast.next is not None:
        slow = slow.next
        fast = fast.next
    slow.next = slow.next.next
    return dummy.next

每次接上較小的那一個

合併兩條遞增串列 a、b。tail 指向已完成輸出的尾端，每次比較 a.value 與 b.value，把較小者接到 tail，然後只推進被取用的那條串列。

已完成部分永遠有序，尚未處理的兩條串列各自有序。當其中一條耗盡，另一條剩下的元素都可以整段接上。值相等時先取 a，保留同來源的先後。

這個實作重接原節點，兩個輸入需為無環、彼此不共享節點的串列。共 n+m 個節點，時間 O(n+m)、額外空間 O(1)。

def merge_sorted(a, b):
    """兩串列必須無環、遞增（可重複），且不能共享任何節點。"""
    dummy = Node(0)
    tail = dummy
    while a is not None and b is not None:
        if a.value <= b.value:
            tail.next, a = a, a.next
        else:
            tail.next, b = b, b.next
        tail = tail.next
    tail.next = a if a is not None else b
    return dummy.next

a=[1,4,8]、b=[2,4,7]，兩個 4 的接入順序是什麼？

看推理

先接 a 的 4，再接 b 的 4，因為比較使用 ≤。輸出值依序為 [1,2,4,4,7,8]。

檢查回文，做完把串列接回去

判斷 1 → 2 → 2 → 1 是否為回文。用快慢指標找到前半尾端，把後半反轉，再從 head 與反轉後入口同步比較。

這裡會暫時改動 next。比較結束後再反轉後半，把它接回前半尾端，讓呼叫前後的串列結構一致。即使中途發現不同，也先保存 matched=False，完成還原才回傳。

總時間 O(n)、額外空間 O(1)。空串列和單節點視為回文。檢查結果時，除了值，也可比對原節點的 next 是否回到原連結。

Python · is_palindrome
def is_palindrome(head):
    """判斷無環串列是否為回文，結束前還原所有 next。"""
    if head is None or head.next is None:
        return True
    first_half_end = fast = head
    while fast.next is not None and fast.next.next is not None:
        first_half_end = first_half_end.next
        fast = fast.next.next

    second_half = reverse(first_half_end.next)
    left, right = head, second_half
    matched = True
    while right is not None:
        if left.value != right.value:
            matched = False
            break
        left, right = left.next, right.next

    first_half_end.next = reverse(second_half)
    return matched

為什麼遇到第一個不同值時，不直接從比較迴圈 return False？

看推理

函式的回傳前工作還包含還原後半串列。先保存 False、跳出比較，再統一反轉接回，能讓兩種結果都遵守同一個輸入保留規格。
