15 · 把數字規律變成可計算的步驟

階乘算出來動輒幾百位數，但題目往往只問尾端幾個零、最大公因數或有幾種選法。這章把這些看起來會算到溢位的數字，縮成幾行整數除法跟餘數。

算 100! 尾端的零，直接數因數 5

100! 的十進位尾端有幾個 0？把整個階乘算出來會產生 158 位數，但答案只取決於裡面有多少組 2×5。

在 1 到 n 的整數中，因數 2 的總數至少與因數 5 一樣多，因此每個因數 5 都能配到一個 2。5 的倍數貢獻一次，25 的倍數再貢獻一次，125 的倍數還要再加一次。答案是 ⌊n/5⌋+⌊n/25⌋+⌊n/125⌋+⋯。

每次直接令 n 整除 5，可把所有層累加起來。時間 O(log₅ n)、工作空間 O(1)，使用整數除法保留精確值。這個思路在問末尾零、整除性、餘數與重複週期時很常見：找出答案需要的因數或狀態，再決定要計算哪些量。

def factorial_zeroes(n):
    if n < 0:
        raise ValueError('n must be nonnegative')
    total = 0
    while n:
        n //= 5
        total += n
    return total

25! 尾端有幾個零？只數 5 的倍數會少算哪一個？

看推理

有 6 個。5、10、15、20、25 提供 5 個因數 5，25=5² 再多提供 1 個，因此是 5+1。

兩種長度要切成一樣大，餘數繼續往下問

長度 84 與 30 的兩條繩子，要全部切成一樣長的小段且用完，每段最多多長？答案是最大公因數 gcd(84,30)。

84=2×30+24。能同時整除 84 與 30 的數，也能整除餘數 24；能整除 30 與 24 的數，也能整除 2×30+24。因此 gcd(84,30)=gcd(30,24)，把較大的數替換成餘數，答案保持不變。

整除步數為 O(log min(|a|,|b|))，工作空間 O(1)；這裡把整數除法視為基本操作。程式先取絕對值，gcd(a,0)=|a|，並約定 gcd(0,0)=0。已知 gcd，最小公倍數可用 abs(a // gcd(a,b) * b) 計算，任一輸入是 0 時結果設為 0。

def gcd(a, b):
    a, b = abs(a), abs(b)
    while b:
        a, b = b, a % b
    return a

計算 gcd(35,14) 的兩次餘數是多少？

看推理

35 % 14=7，14 % 7=0，因此 gcd=7。若要找兩個週期 35 與 14 下一次同時出現的時刻，lcm=35÷7×14=70。

一次問很多質數，讓每個小質數劃掉自己的倍數

要列出 1 到 n 的質數，可以讓已確定的質數共同排除合數。每個合數都有至少一個不超過平方根的質因數。

從 p=2 開始，若 p 還沒被劃掉，就把 p²、p²+p、p²+2p⋯劃掉。p² 以前的 p 的倍數，早已被更小的質因數處理過。當 p²>n，所有合數都已有機會被排除。

標記表占 O(n) 空間，篩法時間 O(n log log n)。只檢查單一整數時，試除到平方根即可；要反覆查詢很多數是否為質數，篩完後查表是 O(1)。

def primes_up_to(n):
    if n < 2:
        return []
    prime = [True] * (n + 1)
    prime[0] = prime[1] = False
    p = 2
    while p * p <= n:
        if prime[p]:
            for multiple in range(p * p, n + 1, p):
                prime[multiple] = False
        p += 1
    return [value for value in range(2, n + 1) if prime[value]]

篩到 49，p=7 這輪會新增劃掉哪個數？

看推理

49。14、21、28、35、42 都已被 2、3 或 5 處理；從 7² 開始剛好留下尚未排除的倍數。

最後一個人參加或不參加，兩種情況加起來

5 個人選 2 人值班，順序不計，有幾組？把最後一個人的選擇拆開，就得到組合數的遞推。

最後一人參加時，從前 4 人選 1 人；最後一人不參加時，從前 4 人選 2 人。兩類互斥且涵蓋所有選法，所以 C(n,k)=C(n−1,k−1)+C(n−1,k)。邊界 C(n,0)=C(n,n)=1。

壓成一列時從右往左更新，讓 row[j-1] 保持上一列的值。時間 O(n·min(k,n−k))、空間 O(min(k,n−k))，以整數運算次數計。Python 大整數會隨答案位數增加運算成本。若順序也計入，排列數是 C(n,k)×k!；例如 5 人選正副隊長，答案 5×4=20。

def choose(n, k):
    if n < 0 or k < 0 or k > n:
        return 0
    k = min(k, n - k)
    if k == 0:
        return 1
    row = [1] + [0] * k
    for i in range(1, n + 1):
        for j in range(min(i, k), 0, -1):
            row[j] += row[j - 1]
    return row[k]

用一列算 C(4,2)，若 j 從左往右更新，會借到哪一列的資料？

看推理

row[j−1] 已被當輪改過，等於借到第 4 列的新值。由右往左才會同時使用上一列的兩個來源，得到正確的 6。
