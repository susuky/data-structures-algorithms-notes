差分、字首樹、位元、最短路徑與連通群組處理不同的重複工作。每一節都從一個具體需求出發，說清楚狀態如何更新。

一整段加值，只改開始與結束

長度 n 的陣列初始全為 0，要對多個閉區間 [left,right] 加 delta。差分先在 left 加 delta，在 right+1 減 delta；最後從左到右累加，讓這個變化只作用在指定範圍。

例如 n=5，對 [1,3] 加 2，差分在索引 1 放 +2、索引 4 放 −2。累加後得到 [0,2,2,2,0]。多次更新可直接把各端點變化疊加。

difference 配置 n+1 格，讓最後一格右側也有停止點。m 次更新各 O(1)，最後還原 O(n)，總時間 O(n+m)、空間 O(n)。回傳整個更新後陣列。

from collections.abc import Iterable

def range_add(n: int, updates: Iterable[tuple[int, int, int]]) -> list[int]:
    if n < 0:
        raise ValueError('n must be nonnegative')
    difference = [0] * (n + 1)
    for left, right, delta in updates:
        if not 0 <= left <= right < n:
            raise ValueError('invalid inclusive interval')
        difference[left] += delta
        difference[right + 1] -= delta
    result, running = [], 0
    for i in range(n):
        running += difference[i]
        result.append(running)
    return result

走過共同字首，再決定是否成為完整單字

加入 app 與 apple 時，前三個字元共用同一條 a→p→p 路徑。字首樹（Trie）每條邊是一個字元，節點的 children 保存下一個可能字元。

走完字元只代表路徑存在；end 才表示某個單字確實在這裡結束。只插入 apple 時，starts_with('app') 為 True，search('app') 為 False。

插入或查詢長度 L 的字串需要走 L 步，字典查詢平均 O(1) 時，總時間 O(L)。節點數至多與所有插入字元總長同階。空字首從根即可成立；插入空字串則將根的 end 設為 True。

from __future__ import annotations

class TrieNode:
    def __init__(self) -> None:
        self.children: dict[str, TrieNode] = {}
        self.end = False

class Trie:
    def __init__(self) -> None:
        self.root = TrieNode()

    def insert(self, word: str) -> None:
        node = self.root
        for char in word:
            if char not in node.children:
                node.children[char] = TrieNode()
            node = node.children[char]
        node.end = True

    def _walk(self, text: str) -> TrieNode | None:
        node = self.root
        for char in text:
            if char not in node.children:
                return None
            node = node.children[char]
        return node

    def search(self, word: str) -> bool:
        node = self._walk(word)
        return node is not None and node.end

    def starts_with(self, prefix: str) -> bool:
        return self._walk(prefix) is not None

一個整數，表示哪些選項已經用過

少量布林狀態可放進 bitmask。第 i 位為 1 表示選項 i 已使用；查詢用 mask & (1<<i)，加入用 |，切換用 ^。

x & (x−1) 每次清除最低位的 1。例如 12 的二進位 1100，做一次變成 1000，再做一次成為 0000，所以有兩個 1。下方 popcount 採非負整數，迴圈次數等於 set bits 數。

固定字長機器整數的位元運算可視為常數；Python int 可隨位元長度成長，超大 mask 的運算成本要隨其儲存字數計算。狀態壓縮 DP 有 2ⁿ 種 mask，適合 n 較小的指派與子集合問題。

def popcount(value: int) -> int:
    if value < 0:
        raise ValueError('this implementation requires a nonnegative integer')
    count = 0
    while value:
        value &= value - 1
        count += 1
    return count

端點怎麼算，決定兩段是否相接

merge_closed 合併閉區間，先依左端排序。新區間 left 若大於目前最後區間的 right，開新的一段；否則重疊，右端改成兩者較大值。

閉區間 [1,3] 與 [3,5] 共享位置 3，所以合併成 [1,5]。活動排程常用半開區間，[1,3) 與 [3,5) 則可前後接續。

每次合併後，答案中的區間已排序且彼此不重疊，最後一段包含所有目前與它接得上的輸入。排序 O(n log n)，掃描 O(n)，回傳新區間清單，空輸入回傳 []。

def merge_closed(intervals: list[tuple[int, int]]) -> list[list[int]]:
    if any(left > right for left, right in intervals):
        raise ValueError('left endpoint exceeds right endpoint')
    merged: list[list[int]] = []
    for left, right in sorted(intervals):
        if not merged or left > merged[-1][1]:
            merged.append([left, right])
        else:
            merged[-1][1] = max(merged[-1][1], right)
    return merged

次方拆成平方，答案一路取餘數

計算 base 的 exponent 次方模 modulus，將 exponent 看成二進位。最低位是 1 就把目前 base 乘進 result；每輪把 base 平方、exponent 右移一位。

每一次乘法後取模，保留與最終餘數相關的資訊。exponent 需非負、modulus 需正；exponent=0 時回傳 1%modulus，所以 modulus=1 時結果為 0。

乘法次數 O(log exponent)，實際算術成本隨整數位元長度而定。模下的除法使用乘法反元素，除數與 modulus 互質時才存在；避免除法的題目可改用前綴與後綴乘積。

def pow_mod(base: int, exponent: int, modulus: int) -> int:
    if exponent < 0 or modulus <= 0:
        raise ValueError('requires exponent >= 0 and modulus > 0')
    result = 1 % modulus
    base %= modulus
    while exponent:
        if exponent & 1:
            result = result * base % modulus
        base = base * base % modulus
        exponent >>= 1
    return result

為什麼模數下可以每次乘完就取餘數？

看推理

同餘關係對加法與乘法保持一致，(a·b) mod m 等於 ((a mod m)·(b mod m)) mod m。

最便宜的未完成路徑，先往外延伸

邊權都是非負時，Dijkstra 每次從最小堆積取出目前最便宜的到達成本。任何尚未處理的路徑只會再加上非負成本，因此這個最小候選可按順序向外鬆弛。

若經 node 到 neighbor 得到更小成本，就更新 distance[neighbor] 並把新候選放進堆積。舊的較貴候選可能仍在裡面；取出時若 cost 與目前 distance 不符，就略過。

起點距離 0，不可達保留 ∞，輸入先檢查所有權重非負。下方採可重複入堆積的寫法，堆積可有 O(E) 項，時間 O(V + E log(E+1))、空間 O(V+E)；簡單圖常寫成 O((V+E) log V)。

from heapq import heappop, heappush
from math import inf

def dijkstra(graph: list[list[tuple[int, int]]], start: int) -> list[float | int]:
    if not 0 <= start < len(graph):
        raise ValueError('start must be a vertex in graph')
    if any(weight < 0 for edges in graph for _, weight in edges):
        raise ValueError('Dijkstra requires nonnegative weights')
    distance = [inf] * len(graph)
    distance[start] = 0
    heap = [(0, start)]
    while heap:
        cost, node = heappop(heap)
        if cost != distance[node]:
            continue  # An old, more expensive entry.
        for neighbor, weight in graph[node]:
            candidate = cost + weight
            if candidate < distance[neighbor]:
                distance[neighbor] = candidate
                heappush(heap, (candidate, neighbor))
    return distance

便宜到達，還剩幾次轉乘

同一城市，花費較低但已用盡轉乘次數的路，與花費較高卻還能繼續轉乘的路，後續資格不同。狀態使用 (城市,已用邊數)，每個狀態各保存最低成本。

最多 K 次中停對應最多 K+1 條邊。堆積按成本取出狀態，走下一條邊時 used+1；達到邊數上限就停止擴展。第一個合法抵達 target 的狀態給出最低成本。

本實作權重非負，可移除無益的環，因此把邊數上限縮到 V−1。start=target 回傳 0，沒有可行路徑回傳 None；max_stops=−1 表示只允許零條邊。狀態數最多 V×(K+2)，實際使用的是縮減後的邊數上限。

def cheapest_with_stops(graph: list[list[tuple[int, int]]], start: int,
                        target: int, max_stops: int) -> int | None:
    # 非負邊的最優路徑可移除環，至多需要 V-1 條邊。
    if not (0 <= start < len(graph) and 0 <= target < len(graph)):
        raise ValueError('start and target must be vertices in graph')
    if max_stops < -1:
        raise ValueError('max_stops must be at least -1')
    if any(weight < 0 for edges in graph for _, weight in edges):
        raise ValueError('requires nonnegative weights')
    max_edges = min(max_stops + 1, len(graph) - 1)
    distance = [[inf] * (max_edges + 1) for _ in graph]
    distance[start][0] = 0
    heap = [(0, start, 0)]
    while heap:
        cost, node, used = heappop(heap)
        if cost != distance[node][used]:
            continue
        if node == target:
            return cost
        if used == max_edges:
            continue
        for neighbor, weight in graph[node]:
            candidate = cost + weight
            if candidate < distance[neighbor][used + 1]:
                distance[neighbor][used + 1] = candidate
                heappush(heap, (candidate, neighbor, used + 1))
    return None

新增連線，把兩個群組合成一個

網路的邊陸續加入，只問兩個節點是否已連通，用互斥集合（Union-Find）。每個節點的 parent 指向同組的上一層，根指向自己；find 找到根，union 連接兩個不同根。

連通群組合併

每一步維持的關係

每棵 parent 樹代表一個連通群組，根保存群組大小。

按大小合併與路徑壓縮：m 次操作約 O((n+m) α(n))。

按大小合併，把較小樹的根接到較大樹。find 沿路走到根後，再把途中節點直接接到根，稱為路徑壓縮。互動顯示各群組與 parent 如何隨連線改變。

原本不同根時，群組數減一並回傳 True；已同根則保持原狀、回傳 False。初始化 O(n)，按大小合併與路徑壓縮後，m 次操作的攤銷成本 O(mα(n))，α 是成長很慢的反 Ackermann 函數。

Union-Find 適合持續加邊的連通性。若要回答兩點之間的實際路徑，保留原圖並走訪；若要刪邊，需依更新模式選擇其他方法。

class UnionFind:
    def __init__(self, n):
        if n < 0:
            raise ValueError("n 必須非負")
        self.parent = list(range(n))
        self.size = [1] * n
        self.components = n

    def find(self, node):
        if not 0 <= node < len(self.parent):
            raise ValueError("節點編號超出範圍")
        root = node
        while self.parent[root] != root:
            root = self.parent[root]
        while node != root:
            previous = self.parent[node]
            self.parent[node] = root
            node = previous
        return root

    def union(self, a, b):
        root_a, root_b = self.find(a), self.find(b)
        if root_a == root_b:
            return False
        if self.size[root_a] < self.size[root_b]:
            root_a, root_b = root_b, root_a
        self.parent[root_b] = root_a
        self.size[root_a] += self.size[root_b]
        self.components -= 1
        return True

把幾個工具放到同一個需求裡

計算最高同時負載：每個閉區間加 1，用差分還原各位置負載，再取最大。若是最少會議室，時間區間通常採半開，依開始時間處理，用最小堆積釋放所有 end≤start 的房間。

找唯一出現一次的值：當其他每個值都恰好出現兩次，XOR 的 x^x=0 與 x^0=x 會讓成對值抵銷，留下唯一者。

計算每項以外的乘積模 m：左到右保存每項左側乘積，再右到左乘上右側乘積。這樣包含 0 的輸入也能處理，時間 O(n)，輸出清單 O(n)，額外累加狀態 O(1)。

這些題目把輸入條件轉成能重用的代數關係：區間變化可累加，最早結束可釋放，相同值可抵銷，左右乘積可分開累計。

def products_except_self_mod(values: list[int], modulus: int) -> list[int]:
    if modulus <= 0:
        raise ValueError('modulus must be positive')
    result = [1 % modulus] * len(values)
    prefix = 1 % modulus
    for i, value in enumerate(values):
        result[i] = prefix
        prefix = prefix * value % modulus
    suffix = 1 % modulus
    for i in range(len(values) - 1, -1, -1):
        result[i] = result[i] * suffix % modulus
        suffix = suffix * values[i] % modulus
    return result
