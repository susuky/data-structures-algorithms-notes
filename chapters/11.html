11 · 讓同一個子問題只算一次

動態規劃先把答案拆成較小的答案，再安排重用。最關鍵的一步，是讓 dp 的每一格都有一句精確的意思。

這一格到底回答什麼

面額 [1,3,4] 要湊 6，先定義 dp[s] 為湊出 s 所需的最少硬幣數。若最後一枚用 coin，前面就要先湊出 s−coin；候選成本是 dp[s−coin]+1。

接著定起點 dp[0]=0，無法到達的狀態用 ∞。所有 coin 為正，所以依賴都在更小的總額，從小到大計算就能在使用前準備好答案。

狀態、轉移、起點、計算順序、最終回傳位置與複雜度，六者互相連接。把每格意思寫完整，迴圈通常就會自然出現。

若 dp[s] 改成「湊出 s 的方法數」，轉移中的 min 應改成什麼？

看推理

改成加總合法來源的方式數；dp[0] 也改為 1，代表空選擇這一種形成零的方法。迴圈順序還要依組合或序列的計數規格決定。

從要的答案往下問，再把結果留下

best(remain) 試每一種可用面額，遞迴問 best(remain−coin)，取最小值加一。best(0)=0，無法湊出時回傳 ∞。外層將 ∞ 轉成 −1。

不同選擇常會到達相同 remain，例如先用 1 再用 3，與先用 3 再用 1。@cache 讓第二次查到相同 remain 時直接拿答案。

若總額 A、不同面額 C，最多 A+1 個狀態，每個看 C 個候選，時間 O(AC)、快取空間 O(A)。遞迴深度最多約 A/minCoin，總額很大時可改用下一節的迭代表格。

from functools import cache
from math import inf


def minimum_coins_memo(coins, amount):
    values = tuple(sorted(set(coins)))
    if amount < 0 or any(c <= 0 for c in values):
        raise ValueError("amount 必須非負，硬幣面額必須為正整數")

    @cache
    def best(remain):
        if remain == 0:
            return 0
        answer = inf
        for coin in values:
            if coin > remain:
                break
            answer = min(answer, 1 + best(remain - coin))
        return answer

    answer = best(amount)
    return -1 if answer == inf else answer

coins=[2,4]、amount=3，best(3) 為何保留 ∞？

看推理

最後用 2 會依賴 best(1)，而 1 無法湊出；4 又大於 3，所以沒有任何可行來源。

最少硬幣

每一步維持的關係

dp[s] 保存湊出 s 的最少枚數，依賴的較小總額已經完成。

O(amount×面額數) 時間、O(amount) 空間。

互動顯示當前格 s、依賴格 s−coin 與候選值。選「無法湊出」案例，觀察 ∞ 如何保留；選零元則直接得到空組合。

想回傳實際硬幣，改善 dp[s] 時一起保存 chosen[s]=coin。從 amount 開始，反覆取 chosen 並扣掉面額，就走回 0。最少枚數無解回傳 −1，方案無解回傳 None，零元方案為 []。

時間 O(AC)、空間 O(A)。這個成本依總額數值 A 增長，若輸入大小用 A 的位元長度衡量，屬於偽多項式（pseudo-polynomial）時間。

def minimum_coins(coins, amount):

def minimum_coin_solution(coins, amount):
    """回傳一組最少硬幣；無解為 None，金額 0 為 []。"""
    values = sorted(set(coins))
    if amount < 0 or any(coin <= 0 for coin in values):
        raise ValueError("amount 必須非負，硬幣面額必須為正整數")
    dp = [float("inf")] * (amount + 1)
    chosen = [0] * (amount + 1)
    dp[0] = 0
    for total in range(1, amount + 1):
        for coin in values:
            if coin > total:
                break
            candidate = dp[total - coin] + 1
            if candidate < dp[total]:
                dp[total] = candidate
                chosen[total] = coin
    if dp[amount] == float("inf"):
        return None
    answer = []
    while amount:
        coin = chosen[amount]
        answer.append(coin)
        amount -= coin
    return answer

看推理

每件只有一份，容量要倒著更新

0/1 背包每件物品最多選一次，總重量不超過 capacity，價值最大。完整狀態可寫成「只看前 i 件、容量上限 c 的最佳價值」；取這件時依賴上一列的 c−weight。

壓成一維後，容量由大到小走。更新 dp[c] 時，dp[c−weight] 還保留上一輪的狀態，因此這件物品只會被用一次。

若由小到大更新，較小容量可能已經放過這件，再拿來更新大容量，就會重複取同一件。下方可不選任何物品，初始 dp 全為 0；重量採正整數，負價值會自然被略過。n 件、容量 W，時間 O(nW)、空間 O(W)。

def knapsack_01(items, capacity):
    """items 為 (正整數重量, 價值)；可不選，總重至多 capacity。"""
    if capacity < 0:
        raise ValueError("capacity 必須非負")
    dp = [0] * (capacity + 1)
    for weight, value in items:
        if weight <= 0:
            raise ValueError("重量必須為正整數")
        for limit in range(capacity, weight - 1, -1):
            dp[limit] = max(dp[limit], dp[limit - weight] + value)
    return dp[capacity]

兩個字串，各自走到哪裡

最長共同子序列（LCS）允許跳過字元，保留相對順序。令 dp[i][j] 是 a 前 i 個字元與 b 前 j 個字元的 LCS 長度。

末字元相同時，把它接在兩邊各退一格的答案後面：dp[i−1][j−1]+1。不同時，至少略過其中一邊的末字元，取 max(dp[i−1][j],dp[i][j−1])。

空前綴與任何字串的共同子序列長度都是 0，所以第 0 列與第 0 欄為 0。長度 m、n 時，時間 O(mn)，下方二維表空間 O(mn)；只求長度可再壓成前後兩列。

def lcs_length(a, b):
    """子序列可跳過元素，但不能改變相對次序。"""
    m, n = len(a), len(b)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if a[i - 1] == b[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
    return dp[m][n]

只能往右或下，前面的格子已經完成

網格每格有進入成本，只能右移或下移。到 (r,c) 的最後一步來自上方或左方，所以成本是 min(上方,左方)+當前格成本。

壓成一列 dp 時，由左到右更新。尚未覆寫的 dp[c] 是上一列同欄的答案，已更新的 dp[c−1] 是這一列左邊的答案。

障礙用 None，遇到障礙把 dp[c] 設成 ∞，讓該路徑停止傳遞。起點成本包含在總和中，沒有路或空網格回傳 None。R×C 網格時間 O(RC)、額外空間 O(C)。

def minimum_grid_path(grid):
    """只能往右或下；None 是障礙。回傳最小總和，無路可走則 None。"""
    if not grid:
        return None
    rows, cols = len(grid), len(grid[0])
    if any(len(row) != cols for row in grid):
        raise ValueError("grid 必須為矩形")
    if cols == 0:
        return None
    infinity = float("inf")
    dp = [infinity] * cols
    for r in range(rows):
        for c in range(cols):
            cost = grid[r][c]
            if cost is None:
                dp[c] = infinity
            elif r == 0 and c == 0:
                dp[c] = cost
            else:
                above = dp[c]  # 尚未覆寫，仍是上一列
                left = dp[c - 1] if c > 0 else infinity
                dp[c] = min(above, left) + cost
    return None if dp[-1] == infinity else dp[-1]

壓縮表格裡的 dp[c]，在更新前與更新後各代表哪一列？

看推理

更新前代表上一列的同一欄；更新後代表當前列的同一欄。這就是由左到右更新時能同時取得上方與左方的原因。

昨天的資格，決定今天能做什麼

交易後有一天冷卻期，且最多持有一股。一天結束分成 hold（持股）、sold（今天剛賣）、rest（空手且可買）。三個狀態保存各自可能的最高現金。

今天 hold 可延續昨天 hold，或從昨天 rest 扣價格買入；今天 sold 只能從昨天 hold 加價格賣出；今天 rest 可延續 rest，或讓昨天 sold 度過冷卻。

同一天的三個新值都讀昨天狀態，所以先保存 old_hold、old_sold、old_rest。初始 rest=0，其餘為 −∞；最後回傳 max(rest,sold)，只採空手的已完成收益。時間 O(n)、額外空間 O(1)。

def cooldown_profit(prices):
    """可多次交易，最多持有一股；賣出後隔天不能買入。"""
    hold = sold = float("-inf")
    rest = 0
    for price in prices:
        if price < 0:
            raise ValueError("價格必須非負")
        old_hold, old_sold, old_rest = hold, sold, rest
        hold = max(old_hold, old_rest - price)
        sold = old_hold + price
        rest = max(old_rest, old_sold)
    return max(rest, sold)

為什麼買入分支讀 old_rest，而不是 old_sold？

看推理

old_sold 代表昨天才賣出，今天仍處於冷卻期。從 old_rest 買入才能符合隔天禁止買入的規則。

把幾種新題翻成狀態

走階梯的序列數：dp[s] 是走到 s 的有序走法數，dp[0]=1；每個最後步長 step 貢獻 dp[s−step]。以 steps=[1,3,4]、s=4 為例，1+3 與 3+1 分別計數。

不取相鄰元素的最大和：讀到 value，候選是沿用 previous，或用 before_previous+value。允許完全不選，所以全負數回傳 0。

最少插入字元形成回文：dp[left][right] 描述區間。兩端相同就縮掉兩端，不同則在兩種縮一端的方案中取小值再加一；依區間長度由短到長填表，時間與空間 O(n²)。

工作指派：mask 表示已使用哪些工作，bit_count(mask) 就是下一個人的編號。嘗試每個未使用工作並更新新 mask，時間 O(n·2ⁿ)、空間 O(2ⁿ)。

def count_step_sequences(n, steps=(1, 3, 4)):
    choices = sorted(set(steps))
    if n < 0 or any(step <= 0 for step in choices):
        raise ValueError("n 必須非負，步長必須為正整數")
    dp = [0] * (n + 1)
    dp[0] = 1
    for total in range(1, n + 1):
        for step in choices:
            if step > total:
                break
            dp[total] += dp[total - step]
    return dp[n]

def minimum_palindrome_insertions(text):
    n = len(text)
    if n == 0:
        return 0
    dp = [[0] * n for _ in range(n)]
    for length in range(2, n + 1):
        for left in range(n - length + 1):
            right = left + length - 1
            if text[left] == text[right]:
                dp[left][right] = dp[left + 1][right - 1] if length > 2 else 0
            else:
                dp[left][right] = 1 + min(dp[left + 1][right],
                                         dp[left][right - 1])
    return dp[0][n - 1]

def minimum_assignment(cost):
    """n 個人各分配一份不同工作；cost[人][工作] 為代價。"""
    n = len(cost)
    if any(len(row) != n for row in cost):
        raise ValueError("cost 必須為方陣")
    size = 1 << n
    dp = [float("inf")] * size
    dp[0] = 0
    for mask in range(size):
        person = mask.bit_count()
        if person == n:
            continue
        for job in range(n):
            if not (mask & (1 << job)):
                next_mask = mask | (1 << job)
                dp[next_mask] = min(dp[next_mask],
                                    dp[mask] + cost[person][job])
    return dp[-1]
