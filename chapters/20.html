20 · 幾何與掃描線

寫幾何題最煩的就是除零跟斜率特例。這章先把左右轉全部換成整數叉積，再用掃描線把連續的時間或座標壓縮成少數幾個起訖事件。

判斷轉彎，用叉積省掉斜率特例

兩段道路有沒有相交？沿著外框走，下一個點是在左邊還是右邊？Geometry 題常把這些判斷寫成同一個式子：cross(O,A,B)=(Aₓ−Oₓ)(Bᵧ−Oᵧ)−(Aᵧ−Oᵧ)(Bₓ−Oₓ)。

把 O→A 當作朝前的方向。叉積為正，B 在左側；為負，B 在右側；等於 0，三點在同一直線。這個值也是有向三角形面積的兩倍。全部都是加減乘法，垂直線可以照常代入。

兩條線段 AB、CD 嚴格交叉時，C 與 D 在 AB 的兩側，同時 A 與 B 在 CD 的兩側。端點相接或共線則另外檢查：候選點的叉積為 0，且 x、y 都落在線段端點的閉區間內，就算相交。以下函式也處理零長度線段。

def cross(origin, a, b):
    return (a[0] - origin[0]) * (b[1] - origin[1]) - (a[1] - origin[1]) * (b[0] - origin[0])

def segments_intersect(a, b, c, d):
    def on_segment(p, q, r):
        return (cross(p, q, r) == 0 and
                min(p[0], q[0]) <= r[0] <= max(p[0], q[0]) and
                min(p[1], q[1]) <= r[1] <= max(p[1], q[1]))
    ab_c, ab_d = cross(a, b, c), cross(a, b, d)
    cd_a, cd_b = cross(c, d, a), cross(c, d, b)
    if ((ab_c > 0 and ab_d < 0) or (ab_c < 0 and ab_d > 0)) and ((cd_a > 0 and cd_b < 0) or (cd_a < 0 and cd_b > 0)):
        return True
    return on_segment(a, b, c) or on_segment(a, b, d) or on_segment(c, d, a) or on_segment(c, d, b)

每次判斷只做固定次數的算術，時間與額外空間 O(1)，以單字長整數算術計。Python int 能保存整數乘積；在固定寬度語言中，兩個座標差相乘的範圍要納入型別選擇。輸入本來就是整數時，保持整數計算，直接用 0 判斷共線。

AB=(0,0)—(4,0)，C=(5,0)。cross(A,B,C)=0，C 在這條線段上嗎？

看推理

C 與 A、B 共線，但 x=5 超出 [0,4]。on_segment 還會檢查座標範圍，因此回傳 False。

橡皮筋包住所有點，留下哪些角

平面上放著一批釘子，拉一條橡皮筋把它們全部包住，碰到的最外層角點就是 Convex Hull（凸包）。先按 x、再按 y 排序，分別走出下凸殼與上凸殼，每次遇到向內凹的轉彎，就把中間那個點拿掉。

下面的 monotone chain 實作只保留角點。下凸殼從左到右走，要求每次都是左轉；若 cross≤0，就彈出上一個點，直到轉彎正確。上凸殼反方向走，使用相同判斷。兩條鏈各去掉一個重複端點後接起來。

一次加入可能彈出多個點，但每個點在一條鏈裡只進出各一次
下凸殼處理目前鏈下一步的理由
加入 (0,0)、(0,2)[(0,0),(0,2)]還只有兩點
遇到 (1,0)[(0,0),(1,0)]右轉，彈出 (0,2)
遇到 (1,1)[(0,0),(1,0),(1,1)]左轉，保留
遇到 (2,0)[(0,0),(2,0)]先彈內凹的 (1,1)，再彈共線的 (1,0)
def convex_hull(points):
    points = sorted(set(points))
    if len(points) <= 1:
        return points
    lower, upper = [], []
    for point in points:
        while len(lower) >= 2 and cross(lower[-2], lower[-1], point) <= 0:
            lower.pop()
        lower.append(point)
    for point in reversed(points):
        while len(upper) >= 2 and cross(upper[-2], upper[-1], point) <= 0:
            upper.pop()
        upper.append(point)
    return lower[:-1] + upper[:-1]

convex_hull 使用上一節的 cross。排序 O(n log n)，兩條鏈的掃描合計 O(n)，額外空間 O(n)。重複座標先去重；一個點直接回傳；全共線則留下字典序兩端。三點以上的結果以逆時針排列，第一點不在結尾重複。

題目若要保留邊上的所有點，轉彎判斷改成只在 cross<0 時彈出，並處理全共線情況，讓同一個點只出現一次。要算凸包面積時，沿答案順序累加 xᵢyᵢ₊₁−yᵢxᵢ₊₁，絕對值除以 2，最後一點要接回第一點。

點集 [(-2,-2),(0,0),(1,1),(2,2),(0,0)] 的凸包會留下哪些點？為什麼迴圈中的 ≤ 包含等號？

看推理

答案是 [(-2,-2),(2,2)]。全都共線，重複的 (0,0) 先被去重，等號則讓位在直線中間的點被彈出，保留兩端角點。

沿著時間軸走，只在開始與結束時更新

三場活動占用 [1,4)、[2,5)、[5,7)。要算有活動的總時數，以及最多同時幾場。Sweep Line（掃描線）把整條時間軸縮成幾個事件：開始加 1，結束減 1；兩個相鄰事件之間，重疊數完全相同。

把相同座標的變化先加在一起。走到新座標 x 時，上一段的 active 已知；active>0 就把 x−previous 加進覆蓋總長。接著才套用 x 的淨變化，新 active 用於下一段。最高重疊數在套用完整批變化後更新。

def interval_union_and_peak(intervals):
    changes = {}
    for left, right in intervals:
        if left > right:
            raise ValueError('left exceeds right')
        if left == right:
            continue
        changes[left] = changes.get(left, 0) + 1
        changes[right] = changes.get(right, 0) - 1
    active = length = peak = 0
    previous = None
    for x in sorted(changes):
        if previous is not None and active > 0:
            length += x - previous
        active += changes[x]
        peak = max(peak, active)
        previous = x
    return length, peak

建立至多 2n 個端點，再排序掃過，時間 O(n log n)、空間 O(n)。座標可為負，區間可重複；相同區間出現兩次，重疊數會加 2。空區間 [x,x) 長度為 0，直接略過。

把同樣想法搬到平面，垂直掃描線經過矩形左邊時加入一段 y 區間，經過右邊時移除；兩個 x 事件間的聯集面積是 Δx 乘上目前 y 的覆蓋長度。這時活動狀態可交給經過座標壓縮的 Segment Tree，節點保存覆蓋次數與實際覆蓋長度。事件排序負責走過 x，樹負責維持 y。

輸入 [0,2)、[0,2)、[2,4)、[2,3)，在 x=2 的 active 是多少？覆蓋總長與最高重疊各是多少？

看推理

x=2 有兩場結束、兩場開始，淨變化為 0，active 保持 2。覆蓋區間是 [0,4)，總長 4，最高重疊 2。
