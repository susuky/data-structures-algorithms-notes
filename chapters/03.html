03 · 把過去的資料變成可查詢的狀態

一邊讀資料，一邊問「之前出現過嗎？」。集合、頻率字典、位置字典使用相似語法，保存的資訊卻各自對應不同問題。

查到同一個槽位，接著比對鍵

雜湊表（hash table）先用鍵的雜湊值定位，再比較鍵的相等性。不同鍵可能落進同一個槽位，容器會繼續辨認；程式使用 seen.add(value)，把這項工作交給 set。

鍵要在存放期間維持一致的相等與雜湊行為。整數、字串和內容皆可雜湊的 tuple 可作鍵；list 與 dict 可變，通常不作鍵。tuple 若包含 list，整體也不可雜湊。

雜湊分布良好、鍵的計算與比較為常數成本時，查詢平均 O(1)。一次擴容會搬移既有資料，連續插入以攤銷分析計算；嚴重碰撞時單次查詢可退到 O(n)。長字串鍵還要計入讀取字元的成本。

看推理

直接存 tuple (2,3)，保留兩個欄位的邊界。查詢也使用同樣的 tuple。

第二次遇到，就立即回傳

從左到右掃 [8,3,8,3]，第一個重複事件發生在索引 2 的 8。seen 保存目前位置之前的值：讀到當前值，先查 seen，沒有才加入。

這個更新順序讓每次命中都對應一筆更早的資料。若先加再查，第一筆就會查到自己。輸入為整數清單，沒有重複時回傳 None；平均時間 O(n)，額外空間 O(u)，u 為不同值的數量。

需求只有存在性時，集合已包含足夠資訊。要問位置或次數，再讓字典的 value 保存那個答案。

def first_repeated(nums: list[int]):
    """回傳掃描時首先重複出現的整數；無重複回傳 None。"""
    seen = set()
    for value in nums:
        if value in seen:
            return value
        seen.add(value)
    return None

第三個相同值，會新增幾對

對 [4,4,7,4,7] 計算 i<j 且值相同的配對。第三個 4 抵達時，前面已有兩個 4，它帶來兩組新配對；因此先把 freq[value] 加進答案，再把頻率加一。

新配對數依序為 0、1、0、2、1，總共 4。每一對只在較晚的元素抵達時結算一次，左右位置自然不同，也沒有重複計數。

平均時間 O(n)、空間 O(u)。dict.get(key,0) 讀不存在的鍵時回傳預設值；defaultdict(int)[key] 會建立該鍵。當字典鍵數用來計算不同種類時，要讓鍵的存在與頻率一致。

def count_equal_pairs(nums: list[int]) -> int:
    freq = {}
    pairs = 0
    for value in nums:
        old_count = freq.get(value, 0)
        pairs += old_count
        freq[value] = old_count + 1
    return pairs

兩數和：向過去找搭檔

未排序的 [9,2,7,4] 要找總和 11。讀到 9 時需要 2，字典還沒有；把 9 的索引 0 保存。讀到 2 時需要 9，查到索引 0，答案就是 (0,1)。

補數查詢

每一步維持的關係

查詢時字典只包含較早的位置，同值保留首次索引。

平均 O(n) 時間、O(n) 額外空間。

first_index 保存每個值第一次出現的位置。查詢發生在加入當前值之前，因此 [3,3] 能配對，[3] 則沒有一對可選。setdefault 保留最早索引，讓同一右端有多個搭檔時選到最早左端。

回傳 0 起算索引對；沒有答案時回傳 None。掃描順序使右端最早完成的配對先被找到。平均時間 O(n)、額外空間 O(n)。

def two_sum_any(nums: list[int], target: int):
    first_index = {}
    for index, value in enumerate(nums):
        complement = target - value
        if complement in first_index:
            return first_index[complement], index
        first_index.setdefault(value, index)
    return None

把區間和改成一次歷史查詢

要數有多少非空連續區間的總和等於 target。寫出前綴關係 P[j]−P[i]=target，移項得到 P[i]=P[j]−target。右端 j 已知時，只需查過去有幾個符合的前綴。

freq 初始為 {0:1}，代表陣列開始前的空前綴。每讀一個值更新 prefix，先把 freq[prefix−target] 加到答案，再增加目前 prefix 的頻率。多個位置可能有相同前綴，每一個都是不同左端。

例如 [0,0,0]、target=0，每輪查到 1、2、3 個舊前綴，累計 6。這個方法只使用加減相消，正數、零、負數都適用。平均時間 O(n)、額外空間 O(n)；答案最大可達 n(n+1)/2。

def count_subarrays_sum(nums: list[int], target: int) -> int:
    freq = {0: 1}
    prefix = 0
    answer = 0
    for value in nums:
        prefix += value
        answer += freq.get(prefix - target, 0)
        freq[prefix] = freq.get(prefix, 0) + 1
    return answer

最長存最早，最短存最近

同樣查 P[j]−target，若目標改成最長區間，就希望左端 i 越小越好。字典保存前綴第一次出現的位置，後續同值前綴保留原紀錄。

對 [1,−1,1]、target=1，前綴是 0、1、0、1。最後的 j=3 配上最早前綴 0 的 i=0，得到長度 3；若把 0 的位置更新為 2，就只剩長度 1。

求個數存頻率，求最長存最早位置，求最短非空區間存最近位置，列出所有區間則存位置清單。查詢式相同，value 的含義跟著目標改變。此處回傳半開區間，同長取較早，無解回傳 (0,0)。

def longest_subarray_sum(nums: list[int], target: int) -> tuple[int, int]:
    """回傳最長非空符合區間，同長取最早；無解回傳 (0, 0)。"""
    first_position = {0: 0}
    prefix = 0
    best = (0, 0)
    for end, value in enumerate(nums, start=1):
        prefix += value
        needed = prefix - target
        if needed in first_position:
            start = first_position[needed]
            if end - start > best[1] - best[0]:
                best = (start, end)
        first_position.setdefault(prefix, end)
    return best
演算法要回答的核心問題雜湊容器中應當保存的資料型態
某個狀態是否曾經出現過set 中的唯一鍵
歷史上能與當前狀態拼成幾組答案dict：鍵 → 累積出現頻率
固定右端，尋求跨度最大的最長區間dict：鍵 → 第一次出現的最早位置（setdefault 不覆蓋）
固定右端，尋求跨度最小的最短非空區間dict：鍵 → 最近一次出現的位置（先查詢後覆蓋更新）

重複字元出現，左端跳到哪裡

讀取 abba 時，第二個 b 迫使 left 跳到索引 2，視窗剩 b。最後的 a 上次出現在索引 0，已經位於視窗外，所以 left 維持 2，得到 ba。

更新式是 left=max(left,last[ch]+1)。max 讓左端只前進；過去已排除的重複字元不會被重新收進視窗。last 隨後更新為目前 right。

每輪留下以 right 結尾的最長無重複視窗，與目前最佳比較即可。回傳半開區間，同長取最早，空字串回傳 (0,0)。平均時間 O(n)、空間 O(u)，索引遵循 Python str 的碼位。

def longest_unique_window(text: str) -> tuple[int, int]:
    """最長無重複字元區間；同長取最早，回傳半開邊界。"""
    last_position = {}
    left = 0
    best = (0, 0)
    for right, char in enumerate(text):
        left = max(left, last_position.get(char, -1) + 1)
        if right + 1 - left > best[1] - best[0]:
            best = (left, right + 1)
        last_position[char] = right
    return best
text = "abba"

把會影響答案的資訊放進鍵

arc 與 car 的字母次數完全相同，可以用同一個 26 格計數 tuple 分組。arr 的 r 出現兩次，會落在另一組。這裡輸入限 a–z，空字串得到全零 tuple；輸出保留組內與首次分組的順序。

鍵的選法也用在搜尋狀態。迷宮裡同一座標若剩餘穿牆次數不同，後續能走的路就不同；鍵應是 (row,col,remaining)。只保存會影響後續可能性的維度，就能合併等價狀態。

W 個單字總長 L、字母表大小 A，建立計數鍵平均花 O(L+WA)，儲存鍵 O(GA)，分組中的單字參照 O(W)。固定 A=26 可簡寫為 O(L+W) 時間。任意字元集可用排序後字元或字元頻率對作鍵。

def group_anagrams(words: list[str]) -> list[list[str]]:
    """只接受 a 到 z；保留各組輸入順序及分組首次出現順序。"""
    groups = {}
    for word in words:
        counts = [0] * 26
        for char in word:
            if not "a" <= char <= "z":
                raise ValueError("只接受小寫英文字母 a 到 z")
            counts[ord(char) - ord("a")] += 1
        key = tuple(counts)
        groups.setdefault(key, []).append(word)
    return list(groups.values())

為什麼把兩個欄位用 '|' 直接接起來可能撞到相同字串？

看推理

('a|b','c') 與 ('a','b|c') 都會變成 a|b|c。tuple 保留兩個欄位的分界，直接用 (欄位一,欄位二) 即可。

三種問題，三種字典內容

即時收到使用者 ID，判斷是否重複只要 set；查累積造訪次數用 ID→次數；回報最早造訪位置用 ID→首次索引。三者都按到達順序處理資料，但留下的資訊各不相同。

再試 [0,0,0] 的零和區間：頻率字典算出 6，集合只能知道「有這個前綴」，會丟掉不同左端的數量。若改求最長區間，保存前綴 0 最早位於邊界 0，就能回傳整段。

把問題改一句話，檢查 value 是否跟著換。這是設計狀態時最實用的練習。

同一前綴值，若要回傳所有合法區間，字典裡需要保存什麼？

看推理

保存該前綴出現過的所有邊界位置。每個右端查到清單後逐一形成區間；輸出可能達 Θ(n²)，成本要包含列出的答案數量。

查詢的時刻，決定字典代表哪段歷史

先把查詢式寫清楚：找 value、找 target−value，或找 prefix−target。接著決定查到後要回傳存在性、次數、最早位置，還是全部位置。

處理當前元素之前，字典通常代表已完成的歷史；本輪完成後，再把新資訊加入。這個時間順序會同時處理「不同索引」與「非空區間」。

測試重複值、target=0、空輸入與同長平手，再看複合鍵是否包含所有會影響未來的條件。

first_position 與 last_position，什麼時候可以覆蓋？

看推理

first_position 只在第一次看見鍵時寫入；last_position 每次處理完都更新。兩個名字各對應一種清楚的時間語意。
