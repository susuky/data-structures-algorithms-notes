10 · 沿著選擇樹找出所有可能

回溯把一個大選擇拆成許多小決定。每進一層加入一個選擇，每回一層撤銷它；途中一旦看出後面走不到答案，就剪掉那條分支。

每個位置選或不選

要列出 [A,B,C] 的所有子集合，對每個位置各做一次「選／不選」。一條從根到葉的路徑就是一份答案，三個位置產生 2³=8 個子集合。

選擇與撤銷

每一步維持的關係

每層決定一個數；返回時 path 還原成進入該層的內容。

最壞 O(n·2ⁿ) 含答案複製，路徑空間 O(n)。

dfs(i) 處理第 i 個位置之後的選擇；path 保存此前已選內容。i 等於長度時，把 path 的複本加入答案。位置各自獨立，所以輸入值若重複，這個基本版本可能產生值相同的輸出。

下方互動再加上目標總和，觀察選擇、撤銷與剪枝如何改變狀態。基本 subsets 全列舉包含 2ⁿ 個答案，複製輸出總成本 Θ(n·2ⁿ)，遞迴路徑空間 O(n)，答案空間另計。

def subsets(items):
    """items 中的位置視為不同選項；若值相同，輸出可能值相同。"""
    answer, path = [], []

    def dfs(i):
        if i == len(items):
            answer.append(path.copy())
            return
        dfs(i + 1)                 # 不選第 i 個
        path.append(items[i])      # 選擇
        dfs(i + 1)                 # 探索
        path.pop()                 # 撤銷

    dfs(0)
    return answer
步驟目前呼叫／動作path已儲存答案
1不選 A，不選 B，到 i=2[][[]]
2回到 i=1，選 B[B][[],[B]]
3撤銷 B，回到 i=0，選 A[A]不變
4不選 B，到 i=2[A]再加入 [A]
5回到 i=1，選 B，到 i=2[A,B]再加入 [A,B]
6先撤銷 B，再撤銷 A[]四份獨立的答案保留下來

原始文件與題目：LeetCode 78．Subsets

子呼叫回來，現場要跟進去前一樣

走某條分支時，path.append(value) 改變了共用清單。子呼叫完成後用 path.pop() 撤銷，下一條分支才會從相同的起點開始。

例如先走 [A,B]，返回後 pop 掉 B，path 回到 [A]，接著才能探索 [A,C]。若少了撤銷，下一條路會帶著上一條路的選擇。

保存答案使用 path.copy()。答案清單要保存當下內容，後續修改 path 時，那份答案仍維持原來的值。used、集合、棋盤位置等共用狀態也遵守同樣的進出對稱。

answer.append(path) 保存的是什麼，之後 pop 會發生什麼？

看推理

保存同一個可變清單的參照。後續 pop 會改到所有指向它的項目；使用 path.copy() 才能保留該步答案。

組合往後選，排列選任何未使用位置

組合只關心選到哪些項目，用 start 限制下一次只能選更右的位置，避免 [A,B] 與 [B,A] 重複出現。排列關心順序，每一層可選任何尚未使用的位置，使用 used 記住當前路徑用過誰。

值有重複時，先排序。unique_permutations 在同一層讓相等值按照固定先後取得資格：前一個相等值尚未使用時，略過後一個；前一個已在目前路徑中時，後一個可以接著選。

n 個相異值最多有 n! 個排列，輸出複製需 O(n·n!)。去重規則縮減實際分支數，path 與 used 仍只需 O(n) 額外空間。

def unique_permutations(items):
    values = sorted(items)
    used = [False] * len(values)
    answer, path = [], []

    def dfs():
        if len(path) == len(values):
            answer.append(path.copy())
            return
        for j, value in enumerate(values):
            if used[j]:
                continue
            # 同層中，先使用前一個相同值，固定相同值的相對次序。
            if j > 0 and values[j] == values[j - 1] and not used[j - 1]:
                continue
            used[j] = True
            path.append(value)
            dfs()
            path.pop()
            used[j] = False

    dfs()
    return answer

[]A₀ 可選；A₁ 因 A₀ 未用而跳過只開一次以 A 起頭的分支
[A₀]A₁ 的前一個 A₀ 已用允許 [A₀,A₁,B] → AAB
[A₀]改選 B，最後選 A₁得到 ABA
[B]先選 A₀，再選 A₁得到 BAA
[]所有第一個候選已處理恰有三個值不同的結果

剩下的數字，還湊得出目標嗎

從正整數清單恰選 k 個位置，每個最多一次，總和要等於 target。狀態是 start、還需幾個 need、還差多少 remain；排序後，下一層從 j+1 開始。

剩餘項目少於 need 就停止。再算可選的最小 need 個總和與最大 need 個總和，若 remain 落在兩者之外，整條分支都無解。這是用上下界剪枝。

choose_k_sum 用前綴和快速計算這些界，並在同一層略過相同值的重複分支。k=0、target=0 產生空組合；正值假設讓超過 remain 後可停止繼續選更大的值。

def choose_k_sum(numbers, k, target):
    """恰選 k 個位置、每個至多一次；回傳不重複的值組合。"""
    if k < 0 or any(x <= 0 for x in numbers):
        raise ValueError("k 必須非負，數值必須為正整數")
    values = sorted(numbers)
    n = len(values)
    prefix = [0]
    for x in values:
        prefix.append(prefix[-1] + x)
    answer, path = [], []

    def dfs(start, need, remain):
        if need == 0:
            if remain == 0:
                answer.append(path.copy())
            return
        if n - start < need:
            return
        smallest = prefix[start + need] - prefix[start]
        largest = prefix[n] - prefix[n - need]
        if remain < smallest or remain > largest:
            return
        for j in range(start, n - need + 1):
            if j > start and values[j] == values[j - 1]:
                continue
            if values[j] > remain:
                break
            path.append(values[j])
            dfs(j + 1, need - 1, remain - values[j])
            path.pop()

    dfs(0, k, target)
    return answer

以 [1,2,2,4,5]、k = 3、target = 8 追蹤，答案是 [1,2,5] 與 [2,2,4]。

剩餘值 [2,4,7]，還需選兩個，remain=5，可以立即停止嗎？

看推理

可以。最小兩個的總和已是 2+4=6，大於 5，後續任何兩個都不會更小。

皇后放進一列，三組限制一起更新

n 皇后每一列放一個。row 由遞迴深度決定，只需選 col；已用欄位、下降對角線 row−col、上升對角線 row+col 各用一個集合。

若 col、row−col、row+col 都未被占用，就把這三項加入集合、把 col 加進 path，再處理下一列。返回後把三項全部移除。

輸出的一串欄編號，第 r 項就是第 r 列皇后的位置。到 row=n 時保存答案；n=0 產生一個空擺法。逐列放置讓同列衝突從狀態設計中直接消失。

def queens_columns(n):
    """每個解是一串欄編號，第 r 個值表示第 r 列皇后的欄。"""
    if n < 0:
        raise ValueError("n 必須非負")
    columns, diagonal_down, diagonal_up = set(), set(), set()
    path, answer = [], []

    def dfs(row):
        if row == n:
            answer.append(path.copy())
            return
        for col in range(n):
            if (col in columns or row - col in diagonal_down
                    or row + col in diagonal_up):
                continue
            columns.add(col)
            diagonal_down.add(row - col)
            diagonal_up.add(row + col)
            path.append(col)
            dfs(row + 1)
            path.pop()
            columns.remove(col)
            diagonal_down.remove(row - col)
            diagonal_up.remove(row + col)

    dfs(0)
    return answer

為什麼同一條斜線可以用 row−col 或 row+col 辨認？

看推理

沿右下方向每走一步，row 與 col 同增 1，差保持不變；沿左下方向 row 增 1、col 減 1，和保持不變。

兩條路會不會遇到同一個後續問題

回溯描述如何探索選擇，DFS 描述走訪順序，記憶化則保存某個狀態的答案。若不同路徑到達同一組完整狀態，且後續解相同，就能重用結果。

例如最少硬幣只問剩餘總額 remain，面額固定時，走到同一 remain 的後續最少枚數相同。列出全部排列時，剩餘可用項目與已選路徑都影響要輸出的內容，狀態要依需求定義。

判斷是否可快取，就問相同鍵是否保證相同後續答案。漏掉已用位置、剩餘資源等條件，會把不同問題誤合併；加入無關歷史則會失去重用機會。

找單字路徑只用 (row,col,i) 快取，還可能少什麼？

看推理

目前路徑已使用哪些格子。兩條路到相同位置與字元進度，剩餘可走格子仍可能不同。

把新限制放進下一層

列出不相鄰位置時，選了 i 就直接遞迴到 i+2；不選則到 i+1。狀態轉移本身就跳過衝突位置。

生成 n 對合法括號時，opened<n 才能加左括號，closed<opened 才能加右括號。每個前綴都維持合法，走到 closed=n 時保存完整字串。

網格尋字時，狀態包含位置、字元進度與目前路徑用過的格子。選進一格後標記 used，返回時移除；下方 word_exists 以 finally 確保提早成功返回時也撤銷。空單字回傳 True，同一路徑每格最多使用一次。

這三個練習都把限制放在展開下一步之前，讓探索集中在仍有機會完成的前綴。

def nonadjacent_slots(n):

        path.append(i)

def balanced_parentheses(n):
    if n < 0:
        raise ValueError("n 必須非負")
    answer, path = [], []

    def dfs(opened, closed):
        if closed == n:
            answer.append("".join(path))
            return
        if opened < n:
            path.append("(")
            dfs(opened + 1, closed)
            path.pop()
        if closed < opened:
            path.append(")")
            dfs(opened, closed + 1)
            path.pop()

    dfs(0, 0)
    return answer

def word_exists(board, word):
    """矩形字元格；上下左右相鄰，同一次路徑不得重複使用格子。"""
    if not word:
        return True
    if not board:
        return False
    rows, cols = len(board), len(board[0])
    if any(len(row) != cols for row in board):
        raise ValueError("board 必須為矩形")
    if cols == 0 or len(word) > rows * cols:
        return False
    used = set()

    def dfs(r, c, i):
        if (r < 0 or r >= rows or c < 0 or c >= cols
                or (r, c) in used or board[r][c] != word[i]):
            return False
        used.add((r, c))
        try:
            if i == len(word) - 1:
                return True
            return any(dfs(r + dr, c + dc, i + 1)
                       for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)))
        finally:
            used.remove((r, c))  # 成功提早回傳時也必定撤銷

    return any(dfs(r, c, 0) for r in range(rows) for c in range(cols))
